# Introduction

Rate My OTT is a browser extension that puts the IMDb rating on every title while you browse Netflix. Each title card gets one small yellow label with the score in its top-right corner (the modal's "More Like This" cards in the top-left, beside Netflix's own duration), the hero at the top of a page gets "• IMDb 8.5" in its metadata line, the preview that opens when you hover a card gets "IMDb 8.5" beside its duration, and the title modal gets an "IMDb:" row with the score and vote count beside its cast and genres, linking to the IMDb page. Search results stay bare: Netflix states no year for them, and the extension never guesses. An optional threshold on the options page fades the artwork of titles rated below it. Other streaming platforms come next.

## How it works

1. A content script on `netflix.com` reads the titles Netflix renders (each card's label), and a second script in the page's own world reads the year, kind, and runtime Netflix fetched for each card and stamps them on it, so the lookup asks for the right "Alpha".
2. The extension's background worker sends them in batches to the Ratings API, `POST /api/v1/ratings`, and remembers the answers for the browser session.
3. The API answers from its own IMDb index: IMDb's daily datasets, imported into Postgres every night and matched by name, kind, year, and runtime, so nothing leaves the API and a title that cannot be matched with certainty gets no score rather than a wrong one.

## What is in the repo

A Bun + Turborepo monorepo, built on [ZeroStarter](https://zerostarter.dev):

- `extension/wxt`: the extension (WXT, React): the Netflix content script, the background worker, a popup, and an options page.
- `api/hono`: the Ratings API (Hono), with an interactive reference at [`/api/docs`](/api/docs).
- `web/next`: this site.
- `packages/db`, `packages/env`, `packages/config`: the Drizzle schema (the `imdb_title` and `imdb_name` index tables, the `imdb_sync` rebuild records), validated env, and the brand config.

[Install](/docs/getting-started/install) is all a user needs. To work on it, [Run the stack](/docs/getting-started/development), then read how the [Ratings API](/docs/getting-started/ratings-api) is shaped.
