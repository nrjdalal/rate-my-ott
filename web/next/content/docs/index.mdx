# Introduction

Rate My OTT is a browser extension that puts IMDb, Rotten Tomatoes, and Metacritic ratings on every title while you browse Netflix. Each title card gets a small badge with the IMDb score, and the title modal gets a ratings row with a link to the IMDb page. Other streaming platforms come next.

## How it works

1. A content script on `netflix.com` reads the titles Netflix renders (from each card's label, and from the open modal's title, year, and kind).
2. The extension's background worker sends them in batches to the Ratings API, `POST /api/v1/ratings`, and remembers the answers for the browser session.
3. The API answers from its Postgres cache and asks [OMDb](https://www.omdbapi.com) only for titles it has not seen (or has not refreshed in a week), so a browsing session costs a handful of provider calls.

## What is in the repo

A Bun + Turborepo monorepo, built on [ZeroStarter](https://zerostarter.dev):

- `extension/wxt`: the extension (WXT, React): the Netflix content script, the background worker, a popup, and an options page.
- `api/hono`: the Ratings API (Hono), with an interactive reference at [`/api/docs`](/api/docs).
- `web/next`: this site.
- `packages/db`, `packages/env`, `packages/config`: the Drizzle schema (one `rating` table), validated env, and the brand config.
